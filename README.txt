ScreenGuard - সিম্পল টেক্সট ব্লকার

1. সব ফাইল GitHub রিপোতে আপলোড করুন (.github ফোল্ডারসহ)।
2. .github ফোল্ডার না গেলে GitHub-এ Add file > Create new file দিয়ে
   নাম দিন: .github/workflows/build.yml  এবং build.yml.txt এর লেখা পেস্ট করুন।
3. Actions ট্যাব > সবুজ রান > Artifacts > ScreenGuard-APK ডাউনলোড।
4. APK ইনস্টল করে অ্যাপ খুলুন > বাটন চাপুন > ScreenGuard Accessibility চালু করুন।
5. Restricted setting দেখালে: Settings > Apps > ScreenGuard > তিন ডট > Allow restricted settings।
